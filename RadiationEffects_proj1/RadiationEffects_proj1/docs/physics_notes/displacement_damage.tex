\title{Displacement Damage}
\begin{document}
\maketitle

Displacement damage begins with a primary knock-on atom. If the transferred energy exceeds the displacement threshold, the lattice atom can leave its site and create a vacancy-interstitial pair. Repeated events can generate clusters and more complex defect structures.

This project treats displacement damage using a simplified proxy connected to Geant4 outputs.
