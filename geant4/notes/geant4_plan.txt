Geant4 plan for this project

Phase 1 output targets
----------------------
1. Total energy deposited in the silicon slab.
2. Depth profile of deposited energy.
3. Count or tagging of hadronic / nuclear interactions.
4. Recoil-energy distribution with better metadata.
5. A recoil-candidate CSV that can be handed directly to the MATLAB
   Module 2 primary-defect model.

Minimal viable demonstration
----------------------------
- single silicon slab geometry
- proton beam first, then neutron comparison
- CSV output sufficient; ROOT optional

Updated recoil CSV intent
-------------------------
recoil_candidates.csv is now treated as a Module 2 interface file,
not just a debug dump.

Each row should represent one recoil-like ion secondary, recorded once at
its first relevant step inside silicon, with enough metadata for:
- recoil-energy threshold screening
- depth binning
- volume/material filtering
- later directional threshold studies

Story to tell in the talk
-------------------------
Geant4 handles the radiation transport and interaction picture.
MATLAB handles the solid-state interpretation layer:
recoil events -> primary defect formation -> defect evolution -> device degradation.
